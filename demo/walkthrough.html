Step 1 · Assumptions

What the question leaves open

The call

A homeowner calling in to report the loss: first notice of loss, not a tech.

The photos

Unspecified, so I tested both. Unguided public photos, and guided photos shot the way a tech or a capture app would.

Xact

No public write API. Mocked as a server that silently drops or corrupts 15% of writes, like a flaky import or UI automation.

Prices

Illustrative codes modeled on Xactimate's WTR category. The quantities and logic are the point.

Step 2 · What breaks, in the order it breaks

Three failure points, three designs

1. Missing information

Calls and photos rarely contain the measurements an estimate needs. A model fills gaps with confident numbers.

Design

Measurements only count with a named reference (outlet, door, tape measure). Facts only count with a quote. Code computes every quantity. Gaps go to a review queue.

2. Context and duplicates

40 photos in one call is expensive, and the same wall gets billed again from every angle.

Design

Hierarchical: a cheap model per photo, then photo→room, then one vision call per room to count distinct walls.

3. Silent write failures

A 200 OK from Xact proves nothing.

Design

Write, read back, diff, remove corrupted lines, retry until it matches.

Step 5 · Measured, not demoed

Each version, 3 callers × 3 runs, scored against the truth

One good run proves nothing. The parts owned by code (review flags, Xact verification) were solid from v1. Grouping photos was the weak link. Splitting work per room (v3) fixed wall counting; telling look-alike rooms apart stayed hard until photos arrived tagged (v5). v5 simulates room tags only: the den, an L-shaped room, still over-counts walls, which a one-step-per-wall capture flow would fix.

Takeaway

Right wherever there's evidence, and explicit about the rest

The agent writes a draft estimate that is correct wherever it has evidence. Every remaining gap becomes a specific instruction for whoever is on site. An agent that knows which 10% it's unsure about beats one that's confident about everything.
